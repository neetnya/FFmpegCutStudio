# FFmpegCutStudio

轻量、克制的 Windows 原生视频处理桌面端（C# `.NET 9` + WPF + `libmpv` + `FFmpeg` + NVIDIA NVENC），将日常最高频的 4 项视频操作整合进同一套界面，避免多软件来回切换。

---

## 一、环境准备与运行

1. **安装 .NET 9 SDK**（或 Visual Studio 2022 17.12+，勾选「.NET 桌面开发」）。
2. **准备 FFmpeg**：从 [gyan.dev FFmpeg Builds](https://www.gyan.dev/ffmpeg/builds/) 下载静态版（含 `ffmpeg.exe`、`ffprobe.exe`、`ffplay.exe` 三个文件），加入系统 `PATH`，或在软件右上角「⚙ 路径」中手动指定。
3. **准备 `libmpv-2.dll`（强烈推荐）**：从 [zhongfly/mpv-winbuild](https://github.com/zhongfly/mpv-winbuild) 或 [shinchiro/mpv-winbuild-cmake Releases](https://github.com/shinchiro/mpv-winbuild-cmake/releases) 下载 `mpv-dev-x86_64-*.7z`，解压出 `libmpv-2.dll`（或 `mpv-2.dll`）放到编译输出目录 `bin/Debug/net9.0-windows/` 与 `FFmpegCutStudio.exe` 同级。
   - **未放置时的兜底**：软件会自动降级为 WPF 内置 `MediaElement` 预览（支持常见 MP4/MOV/WMV），不会黑屏；放入 `libmpv-2.dll` 后自动升级为 D3D11 硬件解码，支持 MKV / HEVC / 10bit / 外挂字幕实时预览。
4. **运行与发布**：
   ```powershell
   # 调试运行
   dotnet run

   # 发布 Release 版（64 位）
   dotnet publish -c Release -r win-x64 --self-contained false
   ```

## 二、界面选项与参数详解

### 1. 顶部全局栏

| 选项 / 控件 | 默认值 | 作用与底层 FFmpeg 参数说明 |
| :--- | :--- | :--- |
| **NVENC 硬件加速** | 勾选 | 涉及**重编码**（精准裁剪、异构视频合并、字幕硬写入）时，使用 NVIDIA 显卡编码器 `-c:v h264_nvenc -preset p4 -rc vbr -cq <画质> -b:v 0`，速度通常是 CPU 软编的 4–10 倍。**取消勾选**则回退到 CPU 软编 `-c:v libx264 -preset veryfast -crf <画质>`（非 N 卡或驱动较旧时取消勾选即可）。 |
| **画质 (CQ/CRF)** | `19` | 控制重编码视频的恒定质量因子（有效范围 `10–35`，**数值越小画质越高、体积越大**）。日常推荐：`16–18` 接近无损肉眼难辨，`19–22` 画质与体积均衡，`23–26` 偏小体积。极速无损模式下此参数不生效。 |
| **⚙ 路径** | 折叠 | 展开后可手动填写 `ffmpeg.exe` 和 `ffprobe.exe` 的完整路径；若已加入系统 `PATH`，保持默认的 `ffmpeg` / `ffprobe` 即可。 |
| **预览内核标签** | 自动检测 | 显示当前生效的预览内核：`libmpv (D3D11)` 表示已成功加载 `libmpv-2.dll`；`WPF 内置预览` 表示程序目录未检测到 DLL，已自动启用兜底预览。 |

### 2. 选项卡一：裁剪 / 合并

#### 上半区：当前视频多段裁剪

| 选项 / 按钮 | 作用与适用场景 |
| :--- | :--- |
| **精准重编码**（单选，默认） | 精确到指定起止帧，彻底消除非关键帧切点造成的开头黑屏、花屏或几秒时间偏差。合并多段时通过单条 `filter_complex`（`trim` + `atrim` + `concat`）一次出片，不生成临时文件；开启顶部 **NVENC** 可大幅提速。 |
| **极速无损 (关键帧)**（单选） | 使用 `-ss <起点> -i <输入> -t <时长> -c copy -avoid_negative_ts make_zero`，不重编码画面与音频，速度取决于磁盘读写。切点会自动吸附到附近关键帧（建议配合 `[` / `]` 键先对齐时间轴上的黄色关键帧刻度再打点）。单段导出直接写入目标文件，不经过临时目录二次拷贝。 |
| **合并导出单文件** | 将分段列表中的全部区间按顺序拼接成一个完整视频输出（例如去掉广告/片头片尾后合成一集）。 |
| **分别导出多文件** | 将列表中的每个分段单独保存为一个独立文件（自动命名为 `原文件名_seg01`、`seg02`…）。 |

#### 下半区：多视频合并

合并前程序会先调用 `ffprobe` 扫描队列中所有视频的编码器、分辨率、像素格式、帧率、音频编码与采样率：

| 合并策略 | 适用条件与底层执行方式 |
| :--- | :--- |
| **智能自动（推荐）** | 自动根据预检结果三档分流：① 参数完全一致 → 走无损直连；② 同为 H.264/H.265 且分辨率/音频一致、仅容器时间戳或元数据有差异 → 自动走 TS 中转无损；③ 编码/分辨率/帧率/音轨不一致 → 自动走统一规格重编码。 |
| **强制无损直连 (`concat demuxer`)** | 跳过判断，直接生成 `list.txt` 执行 `-f concat -safe 0 -c copy`。速度最快、零画质损失，但要求各视频参数严格一致。 |
| **强制 TS 中转无损** | 先将每段无损转为 `.ts`（自动附加 `h264_mp4toannexb` 或 `hevc_mp4toannexb` 比特流滤镜），再拼接回目标容器（AAC 音轨自动附加 `aac_adtstoasc`），最后自动清理临时文件。适合同编码但 MP4 封装时间戳有冲突的片段。 |
| **强制统一规格重编码** | 以队列中第一个视频的分辨率和帧率为基准，对其余视频自动等比缩放并补黑边（`scale` + `pad` + `setsar=1`）、统一色彩格式 `yuv420p`，音频统一重采样为 `48000Hz` 立体声（若某段无音轨自动用 `anullsrc` 补静音），再配合 NVENC/x264 编码输出，彻底避免花屏和音画不同步。 |

### 3. 选项卡二：音视频分离 / 合并

| 勾选框 | 默认值 | 作用与底层参数 |
| :--- | :--- | :--- |
| **提取纯视频 (`-c:v copy`)** | 勾选 | 去除音频轨和字幕轨（`-an -sn -c:v copy`），无损导出原封装格式的纯画面视频。 |
| **提取纯音频 (自动匹配后缀)** | 勾选 | 去除视频轨和字幕轨（`-vn -sn -c:a copy`），并根据 `ffprobe` 检测到的音频编码自动选择安全容器后缀（如 `aac → .m4a`、`mp3 → .mp3`、`opus → .opus`、`flac → .flac`、`pcm → .wav`），避免强行套错后缀报错。 |
| **以较短流为准 (`-shortest`)** | 勾选 | 合并视频与新音频时，当视频和音频时长不一致，自动在较短的那一条流结束时截断输出，避免末尾出现黑屏或无声拖尾。 |
| **音频转 AAC (兼容 MP4)** | 不勾选 | 若外挂音频是 `.flac`、`.wav`、`.ogg` 等 MP4 容器不兼容的格式，勾选此项会自动转码为 `-c:a aac -b:a 192k` 再封装进 MP4；如果音频本身已是 AAC/MP3 或输出选 MKV，则无需勾选。 |

### 4. 选项卡三：软字幕（提取 / 封装）

- **提取内封字幕**：打开视频后自动列出所有内封字幕轨（显示语言标签和编码如 `subrip` / `ass` / `mov_text`），选中后一键按对应格式导出（`.srt` / `.ass` / `.vtt`）。
- **软封装外挂字幕**：不重编码画面和音频（`-c:v copy -c:a copy`），秒级完成：
  - 输出选择 **`.mkv`**：使用 `-c:s copy` 原样保留 `.ass` 特效字体与样式（推荐）。
  - 输出选择 **`.mp4`**：自动转为 `-c:s mov_text`，避免 MP4 直接复制 ASS/SRT 报错。
- **语言标签**（默认 `chi`）：写入字幕轨元数据 `-metadata:s:s:0 language=...`，常用 ISO 639-2 代码：`chi`（中文）、`eng`（英文）、`jpn`（日文）。

---

### 5. 选项卡四：硬字幕（烧录进画面）

| 选项 / 按钮 | 默认值 | 作用与说明 |
| :--- | :--- | :--- |
| **加载到左侧画面预览** | — | 调用 `libmpv` 将选中的 `.srt`/`.ass` 实时叠在左侧播放画面上，烧录前可先检查时间轴同步和排版效果。 |
| **音频无损直拷 (`-c:a copy`)** | 勾选 | 字幕烧录只需要重编码视频画面，勾选后音频直接无损复制，速度更快且音质无损；仅当原视频音频编码与目标 MP4 容器不兼容时才需要取消勾选（取消后自动转 AAC 192k）。 |

> **路径防报错机制**：FFmpeg 的 `subtitles` / `ass` 滤镜对 Windows 盘符冒号（`C:\`）、反斜杠和中文/特殊符号极其敏感。本工具烧录前会自动将字幕复制为系统临时目录下的纯 ASCII 文件名并切换工作目录执行，彻底避免滤镜解析报错。

## 三、剪辑快捷键

| 快捷键 | 功能 |
| :--- | :--- |
| `Space` | 播放 / 暂停 |
| `←` / `→` | 上一帧 / 下一帧 |
| `Shift + ←` / `Shift + →` | 后退 5 秒 / 前进 5 秒 |
| `[` / `]` | 跳转到上一 / 下一关键帧（对齐无损切点） |
| `I` / `O` | 将当前播放位置设为选中分段的起点 / 终点 |
| `N` | 在当前播放位置新增一个裁剪分段 |
| `Delete` | 删除当前选中的分段 |
| 拖拽文件入窗口 | 拖入视频直接加载；拖入 `.srt` / `.ass` 自动填入并预览字幕 |

- **Q：极速无损裁剪几个小时的大视频为什么还是要几十秒？**  
  A：即使不重编码，输出几小时的视频通常仍有数 GB 至十几 GB，受限于硬盘顺序读写速度，耗时数十秒属于正常现象（同尺寸重编码通常需要数十分钟）。
- **Q：勾选 NVENC 后报错怎么办？**  
  A：请确认电脑为 NVIDIA 显卡且驱动支持当前 FFmpeg 的 NVENC API 版本；若报错，直接取消勾选顶部的「NVENC 硬件加速」即可无缝切换回 CPU `libx264` 编码。
